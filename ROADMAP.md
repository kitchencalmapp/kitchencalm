## 🔴 Tier 1 — High Impact, Low Effort

- [x] **📸 Photo Pantry (Hybrid)** — Snap photo of fridge → quick-tap checklist → instant meal matches
- [x] **🆘 Distraction Recovery** — "Lost?" button in Cook Mode shows current step + elapsed time
- [x] **🎤 Voice Commands** — "Next step", "Repeat", "Start timer" during Cook Mode
- [ ] **🎵 Focus Timer / Body Doubling** — Ambient sounds + visual focus countdown per step
- [ ] **💚 "Good Enough" Shortcuts** — Per-recipe escape hatches ("Skip the garnish, it's fine")
- [ ] **🏆 Streak Gamification** — Milestone celebrations, badges, weekly cooking goals

## 🟡 Tier 2 — Medium Build

- [x] **📅 Weekly Meal Planner** — 7-day grid, auto-fill by energy, generate shopping list
- [ ] **⏰ Expiry Tracker** — "Use by" dates on pantry items, "These expire tomorrow" nudges
- [x] **🥗 Nutrition Snapshots** — Per-meal calories/protein/carbs/fat, weekly planner summary
- [ ] **🔪 Prep-Ahead Mode** — Sunday batch-cooking guidance, visual prep timeline

## 🟢 Tier 3 — Differentiators

- [ ] **🔍 "I Have These Ingredients"** — Type 3 items → find matching meals
- [ ] **🧠 ADHD Micro-Coaching** — Pre-cooking grounding messages, weekly ADHD+cooking tips
- [ ] **👨‍👩‍👧 Family Mode** — Multiple profiles, shared lists, meal adaptation for kids
- [ ] **🤖 AI Photo Detection (Pro)** — Full auto ingredient detection from fridge photos

## 🚫 Never Do (ADHD Community Red Lines)

- Calorie counting / diet culture framing
- Guilt-tripping ("You broke your streak")
- 15+ ingredient recipes
- Complex onboarding
- Push notification spam
- Requiring accounts for basic features
